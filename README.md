# Projeto Y.A.N.A 
Uma plataforma com o objetivo de democratizar o acesso ao atendimento psicológico, utilizando para isso de um sistema online que garante a anonimidade dos usuários e permite que todos possam conversar com profissionais da área sobre seus problemas.
<br>
O projeto conta com chats que permitem uma comunicação em tempo real, por meio de websockets, entre psicólogos e pessoas que precisam de ajuda.
